# Free LLM SaaS Frontend

Frontend completo do SaaS com React + Vite.

## Instalação

```bash
cd frontend
npm install
npm run dev
```

Acesse: http://localhost:5173

## Funcionalidades

- Login e Cadastro
- Chat com IA
- Dashboard de uso
- Configurações e API Keys
- Dark/Light mode
- Responsívo

## Conexão com Backend

Certifique-se de que o backend está rodando em http://localhost:3000
